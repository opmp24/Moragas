# Product

## Register

product

## Users

Admin (Telegram bot operator): sends expense/income messages to a Telegram bot, which classifies via Gemini and stores in Supabase.
End users: family members or individuals with an access key who view transaction history and charts on a dashboard.

## Product Purpose

Moragas lets an admin send financial transactions via Telegram, automatically classifies them with Gemini AI, and provides a clean dashboard for users to track income and expenses. Success = frictionless expense tracking with zero data entry beyond a single Telegram message.

## Brand Personality

Modern, animated, surprising. The landing page is the first and only brand impression (users only see it once before entering the dashboard), so it needs to wow with motion and delight. After login, the dashboard is sober and functional — the brand is split: spectacular entry, calm interior.

## Anti-references

No strong anti-references. Avoid generic SaaS tropes (stock illustrations, gradient buttons, side-stripe borders) per the Impeccable skill's absolute bans.

## Design Principles

- **First impression is the only impression** — the landing page must surprise and delight because users only see it once before entering the dashboard.
- **Motion as brand language** — animations are not decoration; they are the primary vehicle for brand personality.
- **Calm after the storm** — the dashboard interior is clean, fast, and focused. All the wow lives on the landing page.
- **Every detail intentional** — precision in spacing, typography, and color reinforces trust for a finance app.

## Accessibility & Inclusion

WCAG AA. Reduced motion support for all animations.
